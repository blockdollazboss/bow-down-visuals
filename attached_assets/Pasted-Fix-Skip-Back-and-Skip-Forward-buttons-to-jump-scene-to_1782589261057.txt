Fix Skip Back and Skip Forward buttons to jump scene-to-scene.

Problem:
Rewind 5 seconds works, so the transport system is connected.

But Skip Back and Skip Forward are not working.
They should jump from scene to scene.

Do not change:
- Rewind 5 seconds
- Fast-forward 5 seconds
- play/pause
- restart
- scrub bar
- timeline waveform
- captions
- effects
- overlays
- watermark
- aspect ratio icon
- fit mode icon
- fullscreen
- Auto PiP
- Export Doctor
- payments or credits

Only fix:
- Skip Back button
- Skip Forward button
- scene navigation
- active scene sync

PART 1 — BUTTON MEANING

Skip Back button = Previous Scene
Skip Forward button = Next Scene

These are not 5-second buttons.

Keep separate buttons for:
- Rewind 5 seconds
- Fast-forward 5 seconds

PART 2 — USE REAL TIMELINE SCENES

Build scene jump targets from the real timeline, not the old scene list.

Use:
- saved dragged timeline order
- added clips
- deleted clips removed
- trimmed clips
- split clips
- current clip durations

Create a timeline scene map like:

sceneJumpPoints = [
  { sceneId, sceneIndex, clipId, startTime, endTime, duration }
]

Sort by timeline order.

PART 3 — SKIP FORWARD BEHAVIOR

When I click Skip Forward:

- find currentTime
- find the current active scene from sceneJumpPoints
- jump to the startTime of the next scene
- if already on the last scene, stay at last scene start or jump to project end safely

Example:
Scene 1 starts 0:00
Scene 2 starts 0:08
Scene 3 starts 0:16

If current time is 0:04 and I click Skip Forward:
jump to 0:08

If current time is 0:09 and I click Skip Forward:
jump to 0:16

PART 4 — SKIP BACK BEHAVIOR

When I click Skip Back:

- find currentTime
- find current active scene from sceneJumpPoints

If currentTime is more than 1 second after current scene start:
jump to current scene start first.

If currentTime is already within 1 second of current scene start:
jump to previous scene start.

If already on Scene 1:
jump to 0:00.

Example:
Scene 2 starts 0:08

If current time is 0:12 and I click Skip Back:
jump to 0:08

If current time is 0:08.5 and I click Skip Back:
jump to 0:00

PART 5 — SHARED SEEK FUNCTION

Both Skip buttons must call the same master seek function used by the working Rewind 5 seconds button.

Use one shared function like:

seekMasterTo(targetTime)

It must update:
- master player video currentTime
- project audio currentTime
- timeline playhead
- audio waveform playhead
- active clip
- active caption
- active effects
- active overlays
- transition state
- timecode display

Do not create a separate seek method that only changes UI.

PART 6 — ACTIVE SCENE HIGHLIGHT

After scene jump:
- highlight the new active scene
- highlight the new active clip in timeline
- update Clips section selection
- update right-side selected clip panel if open

PART 7 — KEYBOARD SHORTCUTS

Connect:
Shift + Left Arrow = Skip Back / Previous Scene
Shift + Right Arrow = Skip Forward / Next Scene

Left Arrow should stay:
Rewind 5 seconds

Right Arrow should stay:
Fast-forward 5 seconds
