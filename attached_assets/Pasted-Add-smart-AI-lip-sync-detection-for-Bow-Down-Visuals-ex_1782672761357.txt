- Sync.so integration
- existing lip sync result URL
- existing project audio
- clip order
- captions
- effects
- overlays
- watermark
- payments
- credits

Only add:
- AI lip sync detection
- smart timing diagnosis
- auto offset recommendation
- preview vs export comparison

Goal:
The app should detect whether the mouth is too early, too late, missing offset, wrong audio section, or export mismatch.

Requirements:

1. Add button:
Analyze Lip Sync Timing

This should analyze the selected lip sync scene and show:
- mouth timing status
- audio timing status
- recommended fix
- suggested offset adjustment
- confidence score

2. Add button:
Analyze Export Lip Sync

This should analyze the exported lip sync scene or first 20s export and compare it to the preview.

Show:
- preview offset
- export offset
- export fine tune offset
- total export offset
- offset applied once: yes/no
- offset missing: yes/no
- offset reversed: yes/no
- offset double-applied: yes/no
- export matches preview: yes/no

3. Detection labels should include:
- Perfect / locked
- Mouth too early
- Mouth too late
- Audio starts too early
- Audio starts too late
- Wrong audio section
- Wrong video source
- Offset missing in export
- Offset reversed in export
- Offset double-applied
- Low confidence / manual review needed

4. Add AI recommendation:

Example output:
Detected: Mouth too early
Fix: Delay lip sync video by +0.20s
Confidence: 87%
Recommended button: Export Mouth Too Early x2

A. Metadata detection
Compare:
- saved preview offset
- export offset
- lip sync scene start time
- audio segment start time
- video source URL
- exported video source
- ffmpeg filter offset

B. Audio/video timing detection
Use ffmpeg/ffprobe to extract:
- scene audio waveform
- export audio waveform
- lip sync video duration
- export scene duration
- start/end timing

C. Visual mouth motion detection
Use frame analysis to estimate mouth movement timing:
- detect face/mouth region if possible
- detect mouth open/close movement
- compare mouth movement peaks to vocal/audio peaks
