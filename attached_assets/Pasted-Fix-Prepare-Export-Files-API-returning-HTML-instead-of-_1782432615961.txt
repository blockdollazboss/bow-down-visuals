- master player
- captions
- caption sync
- caption styles
- effects
- overlays
- Auto PiP
- Bow Down AI Guide

Only fix the Prepare Export Files API route and frontend fetch handling.

Required fix:

1. Find the frontend function for:
Prepare Export Files
Prepare Export Files Only
Debug Export Sources

2. Check what URL it is calling.

It should call a real backend API route, not a React route.

Example:
Correct:
POST /api/export/prepare

GET /export/prepare
/export

{
  "success": false,
  "error": "real error message",
  "clips": []
}

If response is HTML, show:
Prepare Export API returned HTML instead of JSON. The frontend is calling the wrong route or the backend route is missing.
