Robust Video Matting (RVM) — MobileNetV3 models, ONNX
======================================================

Live file : rvm_mobilenetv3_fp16.onnx (7,503,483 bytes)
            The engine's model since the one-engine build
            (Oct 25, 2026): the FP16 release asset — half the
            download of the FP32 file it replaced, at the feed
            sizes the live path actually runs (512–640px).
Also kept : rvm_mobilenetv3_fp32.onnx (14,975,696 bytes)
            The previous live model, retained in the repo as the
            rollback asset; no code path loads it.

            recurrent state and all per-frame math run there,
            never in the page.
